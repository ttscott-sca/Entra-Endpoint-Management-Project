# Microsoft Entra ID and Intune Administration Project

## Overview
This project demonstrates identity and endpoint management using Microsoft Entra ID and Microsoft Intune. The project simulates common administrative tasks performed by IT Support Specialists, Help Desk Technicians, and Junior System Administrators in a modern cloud environment.

## Technologies Used

- Microsoft Entra ID
- Microsoft Intune
- Microsoft Endpoint Manager
- Microsoft 365
- Windows 11
- Multi-Factor Authentication (MFA)
- Azure Portal

## Project Objectives

- Create and manage users
- Create security groups
- Assign group memberships
- Configure Multi-Factor Authentication
- Review sign-in activity
- Enroll devices into Intune
- Configure compliance policies
- Create configuration profiles
- Deploy applications
- Manage endpoint security

# Entra ID Tasks Completed
## User Management

- Created cloud user accounts
- Modified user properties
- Reset user passwords
- Disabled and enabled user accounts

## Group Management

- Assigned users to groups

## Identity Security

- Configured Multi-Factor Authentication
- Reviewed sign-in logs
- Examined user activity reports

## Role-Based Access Control (RBAC)

- Reviewed built-in roles
- Assigned administrative roles
- Applied least-privilege principles
