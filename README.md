# Microsoft Entra ID and Intune Administration Project

## Overview
This project demonstrates identity and endpoint administration using Microsoft Entra ID and Microsoft Intune concepts. The project involved reviewing user accounts, groups, devices, authentication methods, administrative roles, and security features commonly used in enterprise environments.

## Technologies Used

- Microsoft Entra ID
- Microsoft Intune
- Microsoft Endpoint Manager
- Microsoft 365
- Azure Portal

## User Management

- Created cloud user accounts
- Modified user properties
- Reset user passwords
- Disabled and enabled user accounts

## Group Management

- Reviewed security groups
- Examined group memberships
- Analyzed group-based access management

## Identity Administration

- Reviewed organizational user accounts
- Examined user properties and account types
- Reviewed password reset functionality
- Analyzed sign-in activity and audit logs

## Role-Based Access Control (RBAC)

- Reviewed administrative roles
- Examined role assignments
- Analyzed delegated administration concepts

## Device Management

- Reviewed registered devices
- Examined device inventory
- Analyzed endpoint management capabilities

## Enterprise Applications

- Reviewed enterprise applications
- Examined application integration options
- Analyzed single sign-on concepts

## Authentication and Security

- Reviewed authentication methods
- Examined password reset policies
- Evaluated identity security features
